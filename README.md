# AAB — the AI · Human Co-Development Studio

آب ("water") · *Ascension for All and Beyond* · beside **zamin** (earth) and **fiza** (air).
By Abhishek Choudhary · AyeAI. Part of the **Zistgah** ecosystem — a new habitat for humanity,
for the AGI era.

An executable studio for co-developing **systems, not just software**, under the
Verification-Gated Human–AI Co-Development method (VGC, doi:10.5281/zenodo.21264248). The
process diagram is the control surface; your intent and progress persist in the browser.

## Standing instruction
A fresh session needs only **"maintain contract and context"** — read `CONTRACT.md` then
`CONTEXT.md`.

## Run
Open `index.html`, or the hosted page at https://zistgah.org/aab/. No backend, no install.

## Publish (each step opt-in and gated)
```bash
bash zistgah_seed_aab.sh              # SAFE: validate + dry-run only
bash zistgah_seed_aab.sh --push       # push to zistgah/aab (gh; typed PUSH)
ZENODO_TOKEN=... bash zistgah_seed_aab.sh --publish   # mint DOI + OTS (typed MINT)
bash zistgah_seed_aab.sh --issues     # open the Sprint-1 backlog as GitHub issues (typed YES)
```
